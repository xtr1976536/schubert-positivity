# Graham Positivity of Quantum Double Schubert Polynomials

Research repository for the positivity conjecture and its proof. This work is
by Tongren Xiao and Yihua Yue under the guidance of Professor Changzheng Li.
The proof and mathematical arguments are ours; Codex was used only for draft
organization and language polishing. The manuscript is still being discussed
with Matthew J. Samuel and is not a final version.

The `manuscript/` directory contains the current working draft and proof note.
The Lean materials are retained as exploratory formalization scaffolding.
